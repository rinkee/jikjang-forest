# 직장의 숲 · 캐릭터 공방

나만의 3D 사원 캐릭터를 만드는 웹사이트입니다. 머리 모양과 색, 눈 모양과 눈 색, 코, 입, 볼, 옷, 바지, 신발, 안경, 모자, 소품, 배경을 골라 꾸밀 수 있습니다.
(모든 캐릭터·마스코트·UI는 이 프로젝트를 위해 새로 만든 오리지널 디자인입니다.)

## 실행 방법

ES 모듈을 쓰기 때문에 파일을 더블클릭(file://)하면 열리지 않습니다. 이 폴더에서 로컬 서버를 띄워 주세요.

```bash
python3 -m http.server 8000
```

그다음 브라우저에서 http://localhost:8000 을 엽니다. 빌드 과정은 없고, three.js는 `vendor/`에 들어 있어 인터넷 연결 없이도 동작합니다(글꼴만 Google Fonts에서 받아오고, 실패하면 시스템 글꼴을 씁니다).

## 할 수 있는 것

- **3D 캐릭터**: 드래그로 360° 돌려보기, 더블클릭으로 한 바퀴 돌기, 손 흔들기·점프 버튼
- **꾸미기**: 피부 8색, 얼굴형 5 · 체형 7, 헤어 19종 × 15색, 눈썹 11 · 눈 18(눈 색 10) · 코 10 · 입 15 · 볼 10, 상의 13 · 하의 8 · 신발 8(옷 색 18), 안경 11 · 모자 14 · 소품 12 · 배경 10
- **툴바**: 🎲 랜덤, 되돌리기/다시하기, 초기화, 도감에 저장(브라우저에 최대 30명), PNG 저장, 공유 링크(#c=…), 소리 켜기/끄기
- **사원증 발급**: 이름·부서·직급을 넣으면 사원증 카드가 만들어지고 이미지로 저장할 수 있습니다
- **단축키**: ←/→ 옵션 이동, [ / ] 탭 이동, R 랜덤, Ctrl/⌘+Z 되돌리기, Shift+Ctrl/⌘+Z 다시하기, Esc 창 닫기

## 하루 (출퇴근 화면) — `day.html`

공방에서 만든 캐릭터가 내 분신이 되어 같이 출퇴근합니다. 폰 세로 화면 기준입니다.

- **출근하기** → 지하철 컷신(탭하면 건너뛰기) → 회사: 의자에 앉아 발을 흔들며 일하고, 일한 1분마다 도토리 1개가 바구니에 쌓입니다
- 퇴근길 지하철에서는 빈 의자에 앉아 졸고, 아침 집에서는 방을 왔다 갔다 걸어 다닙니다
- 퇴근 시간이 지나거나 쉬는 날에 일하면 **1.5배**(야근 수당). 대신 체력이 2배로 닳습니다
- **체력**(0~100, HUD의 ⚡ 막대): 일하면 1시간에 6씩(야근은 12씩) 줄고, 집에서는 1시간에 6씩(자는 동안은 12씩) 찹니다. 9시간 근무하면 절반쯤 남습니다. 체력이 바닥나면 분신이 스스로 지하철을 타고 집에 갑니다(야근은 많아야 4시간 남짓)
- 퇴근하면 **6시간은 집에서 쉬어야** 다시 출근할 수 있습니다(버튼에 남은 시간 표시). 체력이 바닥나서 왔거나, 야근하고 밤 10시~낮 12시 사이에 집에 오면 그 6시간 동안 바로 잠을 잡니다
- 회사 화이트보드의 **오늘의 할 일**은 부서마다 다른 목록에서 날마다 3개씩 바뀌고(`js/day/todo.js`), 근무 시간이 지나는 만큼 하나씩 체크됩니다. 모니터와 TV 화면은 분신 쪽을 봅니다
- **퇴근하기** → 확인 → 지하철 컷신 → 집 → **퇴근 영수증**
- 집에서는 시간대에 따라 출근 준비(5~11시) · 쉬기(11~23시) · 잠(23~5시) 장면이 바뀝니다(위의 '바로 잠' 규칙이 먼저)
- **하늘은 실제 시간을 따라갑니다**(`js/day/sky.js`): 날짜와 시각으로 해의 높이를 계산해(서울 위도, 계절마다 다른 일출·일몰) 창밖 하늘색, 해와 달, 별, 구름, 하나씩 켜지는 건물 불빛, 방 조명, 스탠드·모니터 불빛, 바닥에 비치는 햇살이 조금씩 바뀝니다. 벽시계와 지하철 안내판도 지금 시각을 보여줍니다. 스튜디오에서 날짜와 시각을 골라 미리 볼 수 있습니다
- 퇴근 버튼을 잊으면 분신은 체력이 바닥날 때까지 일하다가 집에 갑니다(그때까지의 도토리는 받습니다)
- 기록은 브라우저에만 저장됩니다(`ccws-day`). 다른 기기에서 만든 캐릭터는 공방의 공유 링크를 `day.html#c=…`로 열면 옮겨집니다

개발용 주소: `day.html?test=1&seed=3&now=2026-11-10T15:20&fresh=1&in=2026-11-10T08:55` (가짜 시계는 별도 저장소 `ccws-day-test`를 써서 실제 기록을 건드리지 않습니다; `&hp=30`으로 체력, `&home=2026-11-10T21:50&sleep=tired`로 집에 온 시각과 바로 잠든 상태를 정할 수 있습니다), 장면만 보기 `dev/sets.html?set=office|subway|home&mood=night&spot=bed`.

## 폰에 앱처럼 설치하기

`manifest.json`(이름·아이콘·세로 전체 화면)과 `sw.js`(한 번 열면 인터넷 없이도 열리게 해 주는 서비스 워커)가 들어 있습니다. 설치하면 홈 화면에 도토리 아이콘이 생기고 `day.html`이 주소창 없이 열립니다.

- **iPhone (Safari)**: 페이지를 열고 공유 버튼 → **홈 화면에 추가**
- **Android (Chrome)**: 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가**

오프라인 동작과 정식 설치는 브라우저 규칙상 **https** 주소(또는 같은 컴퓨터의 localhost)에서만 됩니다. 같은 와이파이의 `http://<맥 IP>:8000`으로 열면 홈 화면에 추가는 되지만, 열 때마다 맥의 서버가 켜져 있어야 하고 인터넷 없이는 열리지 않습니다. 언제 어디서나 쓰려면 GitHub Pages 같은 https 정적 호스팅에 올리면 됩니다. 기록과 캐릭터는 주소(사이트)마다 따로 저장되므로, 주소를 옮기면 공방의 공유 링크로 캐릭터를 다시 옮겨 주세요.

파일을 바꾼 뒤에는 따로 할 일이 없습니다(네트워크를 먼저 쓰고, 안 될 때만 저장본을 씁니다). `sw.js`의 미리 받을 파일 목록을 바꿨다면 `CACHE` 이름의 숫자를 올려 주세요. 아이콘은 `icons/icon.svg`를 고친 뒤 `node tools/shot.mjs tools/icon.html icons/icon-512.png --w 512 --h 512 --dpr 1`(192, 180도 같은 방법)로 다시 만듭니다.

## 스튜디오 (비율·카메라 조정) — `dev/studio.html`

캐릭터 비율(머리 크기, 몸통·다리 길이, 몸 너비)과 출퇴근 장면의 카메라(내려다보는 각도, 거리, 화각, 장소별 중심)를 한 화면에서 바꿔 보는 도구입니다. 폰 화면(실제 앱과 같은 장면), 캐릭터 정면·왼쪽·뒷면·오른쪽(머리 단위 눈금과 몇 등신인지), 장소를 돌려 보며 카메라 위치를 보는 화면이 함께 바뀝니다.

```bash
node tools/studio.mjs
```

그다음 http://localhost:5180/dev/studio.html 을 엽니다. 이 서버로 열면 **💾 코드에 저장**이 `js/tuning.js`를 바로 고쳐서 앱과 공방, 다른 기기에도 적용됩니다(저장은 이 컴퓨터에서 보낸 요청만 받습니다). 다른 서버로 열면 저장 대신 값을 복사할 수 있습니다. 저장 전 값은 이 브라우저에서 **📱 앱에서 보기 / 🎨 공방에서 보기**(`?draft=1`)로 미리 볼 수 있습니다.

## 다리 관절

다리는 엉덩이 아래 피벗 · 무릎(관절 4개가 나눠 굽힘) · 발목으로 굽습니다(`js/char3d.js`의 `LEG_JOINTS`). 몸통에 붙는 맨다리·발·하의·신발·상의의 긴 밑단은 높이와 좌우 위치에 따라 이 뼈대에 자동으로 스키닝되고, 몸통은 그대로 있습니다. 공방에서는 다리를 쓰지 않아 늘 곧게 서 있고, 하루 화면의 장면이 `character.pose.leg(side, t) → { hip: [x, y, z], knee, ankle }`로 자세를 줍니다(hip x가 음수면 허벅지가 앞으로, knee가 양수면 정강이가 뒤로 굽음).

## 파츠 추가하기

`js/parts/` 파일에서 `CC.register('카테고리', [{ id, name, render(ctx) }])` 형태로 등록합니다. 얼굴 파츠는 SVG 문자열을, 3D 파츠는 three.js 오브젝트(또는 `{ head, body, armL, armR, hide }`)를 돌려주면 됩니다. 새 파츠는 `dev/gallery.html?cat=카테고리`에서 바로 확인할 수 있습니다.
